# Streambench Client

## Description
Build a native Mac client for Kafka and NATS messaging systems using a static HTML/CSS/JS website. The client allows users to send and receive messages without needing a database or any payment integration.

## How to Run
1. Clone the repository or download the files.
2. Open `index.html` in your web browser to start using the Streambench client.

## Files
- **index.html**: Main HTML page for the client.
- **styles.css**: Stylesheet for the client interface.
- **script.js**: Contains the client-side logic and interactivity.
